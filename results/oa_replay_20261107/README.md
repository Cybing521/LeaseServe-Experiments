# OpenAlex replay record

Five-seed JSON for the institution-graph replay (`b1_concurrent_v1`, 1M documents, 2,000 events).
This directory is the churn replay, not the source of the paper table (that is `oa_acl_20261107/`); the narrative
record with the exact table is `docs/121-REAL-ACL-OPENALEX.md` in the project tree, not in this
zip. The ACL itself is built by `experiments/cpp/fetch_openalex_acl.py` and
`gen_openalex_acl.py`; the raw OpenAlex dump is not shipped.
